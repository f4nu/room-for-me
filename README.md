# Room For Me

WoW: Forever addon. Hides Looking For Group listings with no open slot for the roles you ticked.

Toggle: gear menu in the LFG window, or `/rfm`.

Install: copy `RoomForMe` into `Interface/AddOns`.

## Screenshots

Filter off: groups already holding three DPS are listed.

![Filter off](curseforge/filter-off.jpg)

Filter on, playing DPS: those groups are gone.
